    The data dictionary lists the data each journey records or exchanges, as the WHO SMART Guidelines DAK does in its component 5. This demonstrator defines no data model of its own: it shows how the existing specifications are used, so each data set is a model one of them already publishes. J1 signs the DVC payload of WHO SMART Trust PHW (DVCMinPreQual) into the CBOR Web Token of WHO SMART Trust (CWT); J2 registers the child with the client record of the WHO Immunization guide (IMMZC4, which is also its update of client details); J3 imports each verified dose as that guide’s Immunization profile (IMMZImmunization); and J4 generates one IHE Verifiable Health Link payload (VHLPayload) per QR code.

    Each element is named <model>.<path> and is listed as its own specification defines it; that specification is the authority, and only the elements the journeys use are shown. “Realised in” says where this guide’s profiles and examples carry the element. The elements are read by the decision-support logic and counted by the indicators.

    The source is dak/data-dictionary.json; this page and the code lists are generated from it. Every person and value in the examples is fictional.

    J1 DVCMinPreQual DVC HCERT payload (PreQual)

    The minimal Digital Vaccination Certificate payload of WHO SMART Trust PHW, with the vaccine coded by its WHO PreQual product id. J1’s birth hospital builds one per dose; J2 reads it unverified on a home visit and J3 reads it again when the clinic verifies it.

    • Logical model: DVCMinPreQual, canonical http://smart.who.int/trust-phw/StructureDefinition/DVCMinPreQual
    • Specification: WHO SMART Trust PHW, package smart.who.int.trust-phw (0.2.0-litlfred)
    • Recorded or read in: J1 Issue the newborn’s birth-dose DVCs in Country A: Build one DVCMinPreQual payload per dose (Task_Payload); J2 Discover and refer an unregistered infant in Country B: Read each DVC unverified (triage) (Task_Read); J3 Verify, import and schedule at the home clinic: Verify each HCERT against the trust list (Task_Verify)
    • Requirements: STT-PAY-001, STT-PAY-002, STT-PAY-003, STT-PAY-005, STT-VER-011
    • Réalisé par : StructureDefinition TrustDemoTaifafekiPatient, StructureDefinition TrustDemoTaifafekiImmunization, Patient TrustDemoTaifafekiSomsak, Immunization TrustDemoJ1HepB, Immunization TrustDemoJ1Bcg

    J1 CWT CBOR Web Token (CWT)

    • Specification: WHO SMART Trust, package smart.who.int.trust (1.5.0)

(Gateway_Verified); Note the failure; decide doses by policy (Task_Unverified)
    • Requirements: STT-CWT-001, STT-VER-001, STT-VER-006, STT-VER-008
