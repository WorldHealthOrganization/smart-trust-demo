    Семейный кошелёк на одном телефоне с отдельной сводкой о здоровье для каждого человека.

    Khamla едет с Somsak одна.

    Кто может получить доступ к записи малыша без телефона Bounmy? Делегирование доступа внутри домохозяйства остаётся открытым вопросом проектирования.

    Политический вывод

    Проектировать с учётом общих устройств («Одна семья, один телефон»), чтобы семьи с единственным телефоном не оставались в стороне.
