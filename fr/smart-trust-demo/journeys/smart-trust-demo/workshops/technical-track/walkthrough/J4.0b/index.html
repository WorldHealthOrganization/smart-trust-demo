    Chapter 4 · Continuity across a borderCross-BorderJ4.0b · 7/8

    Papa crée un lien à partager à la clinique

    Avant le voyage, Bounmy crée un lien QR vers le dossier de Somsak, verrouillé par un code d’accès à 4 chiffres et valable 14 jours (les paramètres de la démonstration : chaque pays fixerait les siens). Le dossier lui-même reste à Onesa.

    🕒 T0 + 12 mois📍 Pont de l’Amitié Onesa-Taifafeki Application de portefeuille familial (partage de lien)

    Qui intervient à ce moment

    BS
    BounmyPère · détient le téléphone familial
    Ravi

    Crée pour Somsak un lien QR protégé par code d’accès, valable 14 jours.

    « C’est moi qui décide qui le voit, et pour combien de temps. »

    Sans cela

    L’envoi de photos ou de PDF des dossiers expose des données et ne peut pas être vérifié par le destinataire.

    Ce qui le rend possible

    Un lien de santé vérifiable : le code QR ne contient qu’un pointeur verrouillé ; les données restent dans le pays de résidence jusqu’à ce que le code d’accès soit donné.

    Voir ce que voit Bounmy (écran S7)

    Le dossier

    Sur papierDéclaréVérifiéPlanifiéPortablePartagé et audité
    Portable

    Lien partageable créé ; les données restent à Onesa

    Conservé dans : registres nationaux du pays Onesa (le code QR n’est qu’un pointeur)

    Transmission : Un code QR sur le téléphone de papa + un code d’accès qu’il peut prononcer à voix haute

    Et si…

    La batterie du téléphone de Bounmy est à plat à la clinique.

    Le lien pourrait être imprimé à l’avance, et les cartes papier originales prouvent toujours les doses à la naissance.

    Message de politique

    Souveraineté des données : le dossier reste à Onesa jusqu’à ce que la famille autorise quelqu’un à l’ouvrir.

    Questions de politique pour la table

    1. T1What makes the IPS readable in another country's system without a bilateral agreement?
    2. T4Where does the gateway read the consent from, and what does it do when the link has expired?
    3. T6What is inside the link QR, and why can a 4-digit passcode be enough?

    Sous le capot

    Ce que font les normes et les outils à ce moment
    Et alors, sur le plan technique

    Le code QR est une clé, pas une copie. Le dossier reste sur le serveur du pays Onesa, et le consentement de la famille (qui, pour combien de temps) est enregistré sous une forme normalisée et appliqué.
