    泰法费基的 Hep B 产品与奥内萨接种计划中的任何条目都不匹配。Chanthason 作出临床判断，系统计算出下一步到期的剂次。

    如果没有这一项

    各国对疫苗的命名和包装各不相同，因此剂次会被遗漏或重复。

    实现的关键

    保留泰法费基的原始代码，并在其旁边添加奥内萨代码；接种计划引擎计算出到期的剂次。

    如果……

    外国疫苗没有自动匹配项。

    这正是本步骤。由护士作出决定——她的决定可以共享，下一位护士就不必再判断。

    政策要点

    绝不覆盖另一个国家的记录：在国家编码旁边保留原始编码。

    供本桌讨论的政策问题

    1. T1How does an implementation guide let two countries keep their own vaccine codes and still count each other's doses?
    2. T4How does the plan definition decide a dose is overdue, and what sets the date of the next one?
    3. T5How does the indicator count a dose given abroad without counting it twice?
