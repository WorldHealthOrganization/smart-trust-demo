    Module T5 · day 1 · 60 min · Verifiable immunization records across borders: the technical track

    From records to charts

    How does a FHIR record become a row, a chart and a coverage number, and who accessed what?

    Day 1. Serves the policy module M2 The reference architecture (DPI-H) and where you stand.

    Sessions

    • 15:30–15:40 · Talk · Talk 4: From records to charts (10 min). How data gets out of the FHIR server and into tables you can chart. A look at FHIR Data Pipes, how one resource becomes a row, and what a dashboard reads. Leads: Data facilitator; supports: Lead facilitator.
    • 15:40–16:30 · Lab · Lab 3: Build your first dashboard (50 min). A guided start in class, then a take-home task. Look at a dashboard built on the data from Lab 2. Add a small batch of new records, run the pipeline again and watch the chart update. Look at the audit events to see who accessed what. You then have about 24 hours to finish a dashboard of your own. Leads: Data facilitator.

    Where it meets the journey

    • J2b: A child born abroad and registered at home enters the coverage denominator here.
    • J3b: Verified doses, including those given abroad, count toward coverage indicators.
    • J4.1: AuditEvents become an access log you can chart.

    结束时，参与者将能够

    • Describe the path from a FHIR resource to a chart
    • Run the pipeline and see new data appear on a chart
    • Read the audit events for who accessed which record
    • Finish a simple dashboard of your own
