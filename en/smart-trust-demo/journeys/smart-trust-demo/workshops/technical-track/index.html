    Verifiable immunization records across borders: the technical track

    The technical track of a general two-day workshop on verifiable immunization records across borders, taught from the journeys J1 to J4.1 of one cross-border family. It runs beside the policy-maker track (M1 to M7): each technical module serves the policy module it is paired with, and both tracks meet in joint sessions each morning and at the close of each day.

    Two days, one cross-border immunization story. Day 1 covers the building blocks and gets everyone running on Heropa. Day 2 is teams building one part of the journey, then seeing it all work together.

    The two days

    A suggested timetable: a host adapts the times, and fills each country presentation with the host country or an invited country.

    Before you run it

    • Agree the joint sessions on both days with the policy track, and who leads each closing slot.
    • Test the hosted classroom environment (Heropa) the week before. Day 2 apps need an emulator or the Wasm web build, since nobody installs Android Studio.
    • Lab 3: set up the dashboard tooling and the shared test data, with help on hand once the apps are seeded.
    • Assign a facilitator to each Day 2 team.
    • Record the full journey once as a fallback for the finale.
