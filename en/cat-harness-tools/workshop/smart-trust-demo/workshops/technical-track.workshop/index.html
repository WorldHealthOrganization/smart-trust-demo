    Verifiable immunization records across borders: the technical track
    description
    The technical track of a general two-day workshop on verifiable immunization records across borders, taught from the journeys J1 to J4.1 of one cross-border family. It runs beside the [policy-maker track](../dpi-h-policy-track/) (M1 to M7): each technical module serves the policy module it is paired with, and both tracks meet in joint sessions each morning and at the close of each day. Two days, one cross-border immunization story. Day 1 covers the building blocks and gets everyone running on Heropa. Day 2 is small groups installing the apps and walking the whole journey together, then seeing it all work live. ## Before you run it - Test the hosted classroom environment (Heropa) the week before. The apps run in an emulator or the Wasm web build, so nobody installs Android Studio. - Seed the shared test data for Lab 2 and Lab 3, and have the dashboard tooling ready. - Record the full journey once as a fallback for the finale.
    audience
    Developers, implementers and digital health architects, walking the journey in small groups, with one of the four apps each
